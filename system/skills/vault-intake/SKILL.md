---

Read `system/methods/content-intake.md`, then its linked check-in procedure and
vault conventions. Select the module and batch before writing. Use existing notes
and source manifests; preserve disagreements and immutable originals.

Complete the batch's source registration, knowledge links, relevant card/memory
updates, scoped index refresh and dated intake receipt. A pending library import
or failed check remains explicit. No global inbox mark for partial batches and no
legacy learned/probe commands or learned-state graph build. Record checks actually
run; the evaluator checks fidelity and continuity separately from link validity.

For an evaluated run, use `tools/agent_run.py` with workflow `intake`, or retain the
host's actual tool trace. Do not backfill read events or self-certify an independent
pass. This skill does not authorize a whole-vault intake, commits or delegation.
