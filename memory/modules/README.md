# Module memory

Use a module ID from `modules/registry.json`. Create `<module-id>/current.md` for
an actual task, containing its question, boundaries, current judgment, competing
explanation, unresolved items, source links, and next dependency.

Do not duplicate the field roadmap. Link to it. Do not infer an active task from
an old roadmap. The registry can route to an existing roadmap even before module
memory exists.
