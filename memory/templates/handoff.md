# Handoff field guide

Create a real entry under the appropriate memory scope; this is not active state.

| Field | Record |
|---|---|
| Identity | Worker ID, role, tool, exact model if reported |
| Scope | Module, question, owned paths, boundaries |
| Date and basis | Update date; user decision or evidence links |
| Result | What was actually completed and where it lives |
| Versions | Source revision or file fingerprint relevant to the result |
| Checks | Commands run and observed outcomes |
| Uncertainty | Strongest alternative, missing evidence, what would change the result |
| Handoff | Next dependency, ownership, and how to resume |
